# Controls, sent FIRST and read before any candidate. Nothing else goes out
# until all three have answered, because every finding in this pass is a claim
# about a COUNT.
#
#  1  reachability  -- is the host answering at all today
#  2  CONTROL-A     -- a host CC certainly covers, so a count > 0 is a real count
#  3  CONTROL-B     -- a TRUE zero, so a count of 0 is a real zero and not a
#                      syntax artefact. `.invalid` is reserved by RFC 2606 and
#                      can never resolve, so this cannot be a false negative
#                      caused by the target actually existing.
