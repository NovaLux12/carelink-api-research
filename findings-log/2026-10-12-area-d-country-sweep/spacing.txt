# ORACLE: body-file mtimes. probe.sh writes each response body
# with `-o bodies/cc-XX.json`, so the kernel sets that mtime when

# does not depend on the thing under suspicion.
#
# LIMIT OF THIS ORACLE — read before reusing it. Git does NOT
# preserve mtimes: on a fresh clone or `git archive` the body
# files all carry the checkout time and the spread collapses to
# 0.0 s. Valid only on the machine that ran the probe, so the
# NUMBERS get committed. Verify the series is real before
# trusting it: the mtime span should equal the harness span.
#

# the canonical one and the disagreement is itself the finding.
